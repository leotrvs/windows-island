# Code of conduct

Windows Island is a small project made in the open, and everyone is welcome to use it, report problems and suggest changes. To keep it a good place for that:

- **Be kind and patient.** Many people here are not developers, and English is not everyone's first language (writing in Portuguese is fine too).
- **Stay on the subject.** Talk about the app and its code. Personal attacks, insults, harassment, discrimination and spam are not accepted.
- **Disagree with ideas, not with people.** A suggestion can be declined; the person who made it is still welcome.
- **Respect privacy.** Never post someone else's personal data, and check what you paste before sharing it: logs, reports and screenshots can contain names, paths and keys.

## What happens when it is not followed

The maintainer can edit or remove comments, issues and pull requests that break these rules, and can block people who keep doing it.

## Reporting a problem

To report behavior that breaks these rules, use GitHub's own "Report content" option on the comment or issue, or open a private security advisory from the Security tab if it must stay private. The maintainer will read it and answer.

This code of conduct applies to the issues, pull requests and discussions of this repository.
