# Roadmap

Ideas planned for upcoming releases, in the order they are expected to land. Nothing here is promised for a specific version.

## Next

- Choose the order of the pages
- A way to start the extension without loading it by hand (publishing it to the browser stores)

## Ideas, not scheduled

- Island themes (colors and style of the pill)
- Calendar: the next meeting a few minutes before it starts

## Later

- Notifications through the official Windows listener, once the app ships as a signed package

## Done

- Install button for the browser extension, system monitor, tuck away, several Claude chats and Claude Desktop permissions, site icons for web audio and notifications, styled tray menu, folding Settings groups that fit their content, smoother volume bar (2.0.1 to 2.3.3)
- Local API and command line, app names on the dots, battery as an activity, page choice, app icons on notifications, volume and brightness, device and network notes, Do not disturb moon, clock and system page, keyboard shortcut, browser extension (2.0.0)
- Sharp islands on monitors with different display scales (1.13.0)
- Screenshot alert, sliding tab pills, sharper Settings text (1.12.0)
- Update flow with progress, languages (en, pt, es, ru), Inter font, smaller alerts, icons in Settings (1.11.0)
- Animated README GIF from sample data, and Settings that opens like a tray flyout (1.10.1)
- Codex icon, usage ring colors, black Settings header, narrower music view (1.10.0)
- Pages in the island, timer page with pause and custom length, shorter music view (1.9.0)
- App icon, Settings with tabs near the tray, discreet and more reliable microphone dots (1.8.0)
- Timer and stopwatch, microphone and camera dots, battery alerts (1.7.0)
- Lighter app: no Windows Forms, about 10 MB smaller (1.6.0)
- Codex activity, limits and alerts (1.5.0)
- Choosing the monitor: primary, a specific one, all, or the one with the mouse (1.4.0)
- Settings window, and the size and position of the island (1.3.0)
- Configurable alert and paused-music durations, and auto-hide (1.2.0)
- Empty island mode (1.1.0)
- Signed automatic updates from GitHub releases (1.0.0)
- Start menu and Desktop shortcuts, created by the installer (0.2.0)
- Reading Claude's limits without Claude Usage Taskbar (0.2.0)
